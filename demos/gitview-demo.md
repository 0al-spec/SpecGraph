# GitView read-only demo

`demos/gitview/` is a static product-workspace bundle for a demo of the public [GitView graph](https://github.com/SoundBlaster/GitView) at source commit `400eedb6cc41fadef70c79a3d8d463eaf8351310`. Its `candidate_spec_graph.json` is a selected-field demo projection, not an independently authored candidate, canonical write, or full-fidelity export. SpecSpace labels the projection candidate-only; the source YAML remains authoritative. This is a fixed snapshot, not automatic GitView synchronization.

The bundle was built by `build_static_artifact_bundle.py` in workspace mode after a real isolated Platform/SpecGraph initialization. The initialization report is a public-safe copy; twelve local `/Volumes/` paths were replaced with `$LOCAL_PATH` before the publisher collected it, because the current publisher redactor does not handle that path prefix. The unchanged original and plan remain local. The bundle passed the publisher safety gate and was read by SpecSpace's HTTP product-workspace provider with a trusted ready binding and 71 nodes / 434 edges. These checks establish demo artifact and consumer behavior, not implementation readiness or production hosting.
